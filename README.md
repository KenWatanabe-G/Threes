# Threes! Game

ブラウザで遊べるThrees!の実装です。AI自動プレイとランキング機能を搭載しています。

https://kenwatanabe-g.github.io/Threes/

## 🎮 ゲーム概要

Threes!は、4×4のグリッド上でタイルをスライドさせて数字を組み合わせるパズルゲームです。

### ルール

- **1と2を組み合わせると3になる**
- **3以上は同じ数字同士で組み合わせると2倍になる**（3+3=6, 6+6=12, ...）
- 各手の後に新しいタイルが1枚追加される
- 移動もマージもできなくなったらゲームオーバー

## ✨ 主な機能

### 🎯 コアゲーム機能

- **12枚デッキシステム**: 完全ランダムではなく、1/2/3が各4枚ずつのデッキから引かれる
- **ボーナスカード**: 最大タイルが48以上の時、大きな数字が出現する可能性
- **次タイルプレビュー**: 次に出てくるタイルを事前に確認
- **スムーズなアニメーション**: タイルの移動、マージ、新規追加、削除をアニメーション表示
- **スワイプ対応**: PC/モバイルの両方で快適に操作可能
- **ドラッグプレビュー**: スワイプ中に移動可能なタイルをリアルタイム表示

### 🤖 AI自動プレイ

- **Expectimax探索**: [halfrost/threes-ai](https://github.com/halfrost/threes-ai) の Go 実装を JavaScript に移植
- **動的探索深度**: 異なるタイル種類数と最大タイル位置の分散から深さを動的に決定
- **65536エントリ評価テーブル**: 行/列ごとに事前計算したスコアテーブルで高速評価
- **デッキ状態を考慮**: 残り 1/2/3 の枚数とボーナスタイル確率も含めて期待値を計算
- **Web Worker 実行**: 別スレッドで動かすため、AI 思考中も UI が固まらない

### 💡 次の最善手サジェスト

- **AIロジックを流用**: 同じ Expectimax 探索で 4 方向のスコアを評価し、最善手を盤面の矢印で提示
- **毎手自動表示**: トグル ON にすると、移動するたびに新しい盤面で再計算
- **方向の見やすい表示**: 最善手は黄色のパルス矢印、合法な他方向は半透明、違法な方向はグレーアウト
- **ランキングへの影響なし**: 通常カテゴリのまま、レートも変動する (AI 自動プレイや Undo とは異なるヒント扱い)

### 🛠️ ユーティリティ機能

- **Undo機能**: 最大10手まで戻せる
- **タイル削除モード**: 戦略的にタイルを1つ削除できる
- **プレイスキルレーティング**: 各プレイの内容からプレイ評価と累積プレイヤーレートを算出（Undo・削除・AIを使ったプレイではレートは変動しない）
- **📈 レート推移グラフ**: ゲーム終了ごとのレートを時系列でグラフ表示（Chart.js）。カテゴリ別に色分けされた点 + ピークレートの水平線 + tooltip でプレイの詳細を確認可能
- **ゲーム状態の自動保存**: 途中状態、次タイル、デッキ情報をlocalStorageに保存
- **ゲーム状態の自動復元**: ページ再読み込み時に前回の続きから再開
- **盤面コピー**: 盤面情報をクリップボードにコピー
- **スコア記録**: ベストスコアの保存

### 🏆 ランキング機能

- **Supabase連携ランキング**: オンラインランキングの保存と取得
- **カテゴリ別ランキング**: 通常、アンドゥあり、なんでもありの3カテゴリに対応（AI使用プレイは「なんでもあり」に登録され、レーティングは変動しない）
- **プレイ回数ランキング**: ゲームオーバー回数を集計
- **自動登録**: ゲームオーバー時にスコアを自動登録
- **ハイスコア更新**: 同一カテゴリでは高いスコアのみを保存
- **プレイヤー名保存**: 名前をlocalStorageに保存

## 🖥️ 使い方

### 基本操作

1. ブラウザで`index.html`を開く
2. 矢印キー（↑↓←→）、スワイプ、またはマウスドラッグでタイルを動かす
3. 同じ数字や1+2を組み合わせて高得点を目指す

### その他の機能

- **New Game**: 新しいゲームを開始
- **Undo**: 1手戻る
- **削除モード**: タイルを削除できるモードに切り替え
- **AIボタン (ロボットアイコン)**: AI 自動プレイの ON/OFF
- **サジェストボタン (電球アイコン)**: 次の最善手を盤面の矢印で表示する ON/OFF (ランキング・レートに影響なし)
- **レート表示**: ヘッダーに現在のプレイヤーレート、ゲームオーバー時に今回の評価と増減を表示
- **コピーボタン**: 盤面をクリップボードにコピー
- **ランキングボタン**: ランキング一覧を表示
- **レート推移ボタン (折れ線アイコン)**: ゲーム終了ごとのレート推移をグラフで表示

## 🌐 ランキング設定

ランキング機能を使うにはSupabaseの設定が必要です。

### ローカル開発時

`config.local.js.example`をコピーして`config.local.js`を作成し、以下を設定します。

```javascript
window.SUPABASE_CONFIG = {
    url: 'https://xxxxx.supabase.co',
    anonKey: 'eyJ...'
};
```

### 関連ファイル

- `config.local.js.example`: ローカル設定サンプル
- `supabase/setup.sql`: テーブル作成用SQL
- `supabase/README.md`: セットアップメモ

## 🎨 UI/UXの特徴

- **動的フォントサイズ**: タイルの数字の桁数に応じて自動調整
- **GPUアクセラレーション**: スムーズなアニメーション

## 🏗️ 技術スタック

- **Pure JavaScript**: フレームワーク不使用
- **Web Worker**: AI 計算を別スレッドで実行
- **CSS3**: アニメーションとグリッドレイアウト
- **HTML5**: セマンティックマークアップ
- **localStorage**: 設定とスコアの永続化
- **Supabase REST API**: ランキング機能
- **Chart.js 4.x**: レート推移グラフ描画（jsdelivr CDN）
